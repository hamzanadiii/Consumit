# Admin control room

Open `/admin` with an administrator session. The five sections are Dashboard, Providers, Test Lab, Diagnostics and Access. Dashboard separates Movies, Series and Anime, with actual member playback measured over 15 minutes. Unknown means insufficient evidence; Source found means resolution passed, not that the browser decoded the recording. Missing services and failed requests stay visible independently.

Use Test in a provider or health row to open Test Lab with that provider and title kind selected. Search the catalog for an exact movie, series or anime; series and anime tests also require an exact episode. Replace the clearly labeled sample titles as needed. Select one provider or any compatible subset; tests run sequentially with per-provider progress. Filter result cards by resolution state and delivery. Each check has a 15-second server deadline, a 20-second shared per-provider cooldown and a 60-request-per-minute route limit. The inspection route is available to authorized admins in every deployment, with admin authorization, Origin checks, provider and configured-region eligibility, upstream-group exclusivity and source validation still enforced. Only this authenticated inspection route gets a 20-second socket/gateway ceiling so its timeout result can reach the operator. Stop cancels remaining work. Browser check plays the first eligible source through Consumit's own player using the saved delivery path (including installed rows tested in Scout) for up to 60 seconds; use Play and seek to another scene. Startup, first frame, seek and observed stalls are separate evidence and reset when a new check starts. Leaving Test Lab stops media. Preview never writes watch progress or member telemetry.

Provider scout contains finite reviewed recipes, including candidates outside the configured roster. The catalog is instantiated through the normal adapter seam, not an arbitrary URL scanner. Its tests never change provider settings or affect circuit/probe evidence. A passing candidate offers a disabled JSON recipe: review its hosts and limits, merge it into the operator-controlled base file, restart the API, then explicitly enable/order it in Providers. Failed candidates need adapter/host review, not broader wildcard permissions. Recipes and evidence are downloaded only when requested; evidence omits signed media, keys, tokens and raw upstream errors.

Providers retains durable staged Save/Discard, roles, enabled state, approved regions, RPM, concurrency, deletion/restoration and revisioned playback order. Diagnostics retains per-browser latency percentiles, circuit reset, bounded retests, subtitle tests and the before/after audit. Access retains existing role management; account administration is outside this slice.

Use Video delivery in a provider row to choose Direct or Proxy, then Save. Direct providers run first and stay direct after failure. Proxy providers run in their separate tier only when the Worker and API independently approve their provider ID and exact media hosts. Awaiting Worker approval means the assignment is saved but that row cannot play yet; registering approval still requires operator configuration and Worker deployment under the relay runbook. API hosts configured reports the API policy only; it does not verify the independently deployed Worker policy or browser delivery. Existing providers, including Vixsrc, remain Direct. A failed save keeps the draft; Discard clears it, and Reset settings restores the base delivery assignment without changing saved order. Added audio stays direct. Configured provider tests use the saved path and report unavailable Proxy approval explicitly; Scout uses saved registrations for installed rows, and the reviewed delivery recipe for uninstalled candidates; approval remains independent. Proxy preview grants expire after at most 90 seconds and are excluded from exports.

For local measurements, run the existing collector and Prometheus without notification receivers:

```powershell
docker compose -f compose.yaml -f compose.dev.yaml -f compose.playback.yaml --profile playback up -d --no-deps --no-build otel-collector prometheus
```

The services are local and free, keep seven days of aggregate measurements, and become useful after normal playback accumulates samples. Prometheus lifecycle control remains disabled by default; the invalid explicit `=false` launch argument is removed. Firing alerts in Admin do not establish external notification delivery. [Prometheus command-line defaults](https://prometheus.io/docs/prometheus/latest/command-line/prometheus/).
