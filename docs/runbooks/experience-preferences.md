## Smoke checks

Use disposable fixture identities where possible; never seed fixture preferences or Favorites into existing member accounts without an intentional save.

- Guest browsing with prompt disabled has no modal; direct `/onboarding` remains usable. If enabling the prompt in a verified build, check Home/catalog/title/Search, Skip/Escape, focus restoration, once-per-version suppression and retained internal destination. Direct Watch and `/_internal/release-check` never show the prompt.
- Fresh account reads return defaults with `saved: false`. A guide-only dismissal may return `saved: true` while `playbackConfigured` remains false. A new account starts from its own defaults; Use device choices changes a draft and only Save writes those guest choices to the account.
- Partial saves preserve other preferences. Movie/series audio, anime SUB/DUB, subtitles/ordered languages, quality and next-episode autoplay survive reload and a second browser session. Confirm defaults are English, anime SUB, English subtitles on, Auto quality and autoplay off.
- Preference read/write failure retains account-scoped choices with retry. Rapid partial writes, owner changes and nested-provider dismissal during bootstrap must not overwrite restored account playback choices. Guest storage denial is visit-only and watching remains available.
- Favorites are optional, max four and deliberate. Back retains the member draft; failed existing-Favorites reads prevent replacement; save failure offers retry/continue without saving. Guests can continue without an account. Completion returns to the safe retained destination and does not manufacture member history or Favorites.
- Direct Watch uses preferences before resolution; later player selections sync semantic intent while the current controls/video remain usable. Unavailable English DUB does not silently switch to SUB. Source changes retain existing progress/history behavior and preference sync failure does not stop playback.
- Check authenticated GET/PATCH no-store, signed-out rejection, rejected foreign-Origin writes, account export and deletion/late-write behavior. Community links point to the supplied destinations, open safely in new tabs and can be hidden on Home independently of guide completion. Check 1440px/390px, both themes, long copy, keyboard controls and horizontal containment.
