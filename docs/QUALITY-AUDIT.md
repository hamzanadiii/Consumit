# Quality audit — 2026-09-25

This audit covers the web application, Fastify API, contracts, shared UI, provider SDK, persistence, and deployment configuration. Findings below are grounded in code or a reproducing check. The fixes in this change address the urgent trust-boundary and broken-gate findings; the remaining items need separate, measured slices.

Current review (2026-10-03): [the project quality review](./audits/project-quality-2026-10-03.md) records current findings and verification. Direct-first playback can enter an explicitly approved Worker relay tier under [ADR 0005](./adr/0005-direct-first-worker-relay.md), which supersedes ADR 0003's direct-only restriction. Public embeds remain deferred; social surfaces are retired from the active personal product.

Historical product status (2026-10-01): browser-direct playback was the only delivery path under ADR 0003. That delivery restriction is superseded; retain the evidence below as historical verification.

Previous product status (2026-09-29): public player embeds and `/v1/embed` routes are deferred and unmounted. The embed findings below record the earlier implementation state and do not indicate that those routes are currently available.

## Evidence and measurements

- The API uses exact-Origin mutation checks and opaque Valkey sessions; provider resolution uses a DNS-pinned, bounded HTTP transport and validates output at the adapter seam. These were retained.
- The catalog uses bounded upstream requests and stale caching; the resolver has a deadline, per-provider attempt budgets, source validation, a cache, and a circuit breaker. No unmeasured caching or ranking rewrite was made.
- Before changes, `bun run check` stopped at seven API lint errors. Separately, API type checking found four errors, and one of 282 API tests failed. `bun run infra:validate` stopped because Terraform is unavailable in this environment.
- Playback tests use an isolated Next build directory and a loopback media server. The latest four-browser run passed 21 scenarios, skipped two HLS cases on Windows Playwright WebKit (which reports HLS as incompatible before requesting a manifest), and had one Firefox native-start timeout under the full matrix load. Firefox then passed all six scenarios with a longer development-server start allowance. WebKit passes native decoding, Direct-to-backup fallback, public-embed recovery, and paused-position recovery. The paused-position bug was reproduced: WebKit accepted the seek on replacement metadata and reset it during pending media work; bounded post-load checks now restore it. A focused Firefox check now covers hydration on Watch and embed routes; it passes without a hydration warning, so the previously recorded disabled-control mismatch did not reproduce in those paths. `bun run infra:validate` reports the missing Terraform prerequisite. k6 is also absent. A synthetic custom-format PostgreSQL 17 snapshot passed a loopback encrypted Restic/SFTP restore drill: full pack reads found no errors, all 23 migrations were up to date after restore, Member/Credential/Profile relationships held, and the member export excluded secret fields. Retention kept the configured representatives and pruned an intermediate same-day snapshot; freshness checks reject a different host. This does not verify the production Storage Box, provider PITR, offsite failure domain, or production RTO. The opt-in metrics images were not fully pulled, so Prometheus and collector startup remain unverified here.
- Provider operations now expose playback-start and stall p50/p95/p99 histograms grouped by a bounded browser family, provider, region, and title kind. Provider health uses the combined browser counts; production measurements remain unavailable until the telemetry stack is deployed and receives representative traffic.
- The existing `tests/playback/load.js` is a controlled-fixture k6 scenario. Production latency, browser bundle cost, database query plans, provider success rates, and restore time remain unmeasured here; no performance or availability target is claimed as achieved.
