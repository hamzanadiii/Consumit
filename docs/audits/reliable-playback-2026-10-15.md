## Member jobs and scope

- Watch an exact movie, series episode or AniList anime episode with available quality, language and captions; keep prior sound until a chosen replacement works and recover honestly when providers fail.
- Choose personal Main Server / Backup order for each title type, retain the Admin default for unranked servers, and stop a finite automatic recovery cycle or select manually.
- Resume only one's own device/account progress, hide a title without deleting its history, and discover recommendations from actual private watch history.
- Choose browsing advertising On/Off with immediate device enforcement, private synchronization and cross-tab notification. Display banners remain removed.
- Retain the current Consumit Player, cinema Watch layout, library, authentication and approved media delivery paths. No new paid services or infrastructure were added.

## Implementation

Contracts remain Zod-authoritative. Per-kind server orders and Ad status extend the existing preference object. Private Continue and recommendation APIs enforce the member and no-store boundary. Owned playback attempts use the current playback cookie and Valkey namespace, bounded source requests, frozen roster, continuation, cancellation, independent delivery health and source revalidation. Personal ordering cannot expand enabled/region/role/relay permissions or spending. Manual selection ends the old cycle; recovery updates and continuations share a step lock. Legacy refresh/manual APIs remain available.

Subtitle discovery includes enabled, region-approved streaming adapters and the existing subtitle adapters. Bounded batches retain previously found tracks and expose query-bound, expiring continuation tokens. Interrupted batches retain unfinished providers; replay does not repeat a completed batch. Preparation rechecks provider authority and supported, bounded, unencrypted subtitle timelines. Browser recovery, retry, language refresh, stale-response guards and actual cue validation expose failures without stopping video.

Stream language switches await engine/clock confirmation. Separate audio retains active output while the pending recording prepares and starts, falls through compatible recordings of that language, and saves language only on successful activation. Gesture-based capability resume, Enable audio, duration checks and manual sync remain explicit. Approved Relay audio capabilities require a separately configured Audio/Both registration and independent host approval; the product API never carries media bytes. Quality menus expose actual supplied renditions and preserve semantic audio intent, position and captions.

Continue watching merges account and exact-owner device rows by freshness, selects one destination per kind/id, retains the 60-second partial-watch threshold and confirms next episodes through canonical metadata. Private Hide preserves progress/history; a later watch restores eligibility. Recommendations use actual private history and existing movie/series/anime adapters, filter watched/dismissed titles, and expose type/sort, Not interested, Undo and reset. Autoplay remains Off by default and uses a 10-second Play now/Cancel countdown. Issue reports offer an unchecked diagnostic opt-in with strict redacted fields; no cookies, credentials or playback URLs are included.

Ad status waits for saved preferences before injection; Off applies on the device and survives account sync failure with Retry. Storage events notify tabs. After an advertising script executes, Off reloads browsing documents to remove installed handlers, preserving active Watch. Unsandboxed external sources are rejected with Off; external players retain explicit progress/subtitle/auto-next limitations.
