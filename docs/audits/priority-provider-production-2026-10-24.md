## Recommendation

Keep one adapter seam and independently configured lookup/media routes. First repair live Mapple/VidBolt behavior with stage-specific evidence. For lookup locations returning 403, require a successful candidate lookup followed by production-origin browser playback before promoting any alternate route. For egress-bound sources, resolution, manifests, segments and renewal must use the matching proven egress. Cloudflare Paid alone does not change provider rejection of a network address.

Where no supported, reliable native route can be demonstrated, retain the provider as unavailable and continue to another accepted provider; an existing external player can be a separately tested fallback. Do not buy an arbitrary VPS, widen host validation, claim that an available session proves playback, or promise that shared caching repairs rejected lookups. Shared caching follows provider-route acceptance.
