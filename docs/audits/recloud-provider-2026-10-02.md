# Recloud anime provider — 2026-10-02

The member requested the Recloud anime adapter from PROVE. The implementation reference is `../PROVE/providers/anime/recloud.ts` from the workspace root. This slice adds an anime-only configured provider while preserving the existing Consumit Player, canonical episode identity, saved Admin ordering, and member progress.

Recloud uses exact AniList ID and episode routes with separate SUB/DUB lanes. Its embed HTML supplies a quoted `sourcesUrl`; Consumit extracts the bounded string without executing JavaScript, restricts the endpoint to same-origin `/stream/getSources`, and validates the returned JSON. Root media, all playlist references, and captions are constrained to HTTPS `cdn.4animo.xyz` without credentials, fragments, or recognizable relay wrappers. A bounded playlist chain and a 16 KiB segment prefix are fetched through the existing DNS-pinned transport without playback Referer/Origin headers. Page/API control requests use Recloud's control headers; the browser source itself has no custom headers. Existing shared manifest parsing, source-expiry validation, skip ranges, and caption contracts are reused.

PROVE intentionally falls back from unmapped DUB to SUB. Consumit's adapter does not: it tries only the requested lane across the three bounded server slots, and rejects conflicting explicit audio labels. Known capabilities are `ja` and `en`, so the strict anime audio policy includes Recloud in both eligible rosters. Missing or unusable media yields an honest miss/failure and the existing player can choose another provider. The new local row is enabled and appended without rewriting existing rows or saved overrides. The example row is disabled. No web changes, media relay, paid service, or new dependency were needed.
